# 合规与边界（COMPLIANCE）

## 1. 授权前提

本项目仅用于分析**本人拥有或已获授权的本地 HTML 快照材料**。使用者应在导入快照前确认：

- 对快照内容拥有合法访问与使用权限；
- 快照不含超出授权范围的个人信息、商业秘密或受限数据；
- 本地处理方式符合所在组织的数据治理与留存要求。

项目不提供任何绕过访问控制、验证码、登录限制、付费墙或反爬机制的能力，也不鼓励对未授权目标进行采集分析。

## 2. 离线运行边界

运行期严格遵守离线约束：

- 不发起 HTTP/HTTPS 请求；
- 不进行 DNS 解析；
- 不加载 CDN、远程字体、图标、图片或分析脚本；
- 不调用远程 API、云数据库、消息队列或对象存储；
- 不依赖浏览器二进制、Selenium、Playwright、截图或渲染服务；
- 不执行快照中的 JavaScript。

Flask 复核台只绑定 `127.0.0.1`，本地静态资源仅来自 `selregress/static/`。CSP 设置 `default-src 'self'`、`connect-src 'none'`、`form-action 'none'`，从策略层阻止外部资源与表单外发。

## 3. 数据与凭据

仓库内 fixture 使用保留域名 `.invalid` 与虚构机构名，例如 `site-a.invalid`、`示例甲单位`。所有 HTML、YAML、JSON、测试与文档均不含：

- 真实密钥、令牌、Cookie、会话或密码；
- 真实公司名、真实个人信息；
- 真实域名、真实 IP、真实可访问目标地址；
- 生产环境导出数据。

示例中的 URL（如 `/notices/a-001`、`/docs/a-001`）均为站内占位路径，不会被访问。

## 4. 只读与最小权限

- CLI 仅读取配置、配方、基线、快照，并写入明确声明的本地台账与报告目录；
- 所有输入路径经 `resolve()` 后必须位于项目根目录内，拒绝 `..` 与符号链接越界；
- SQLite 台账写入使用单事务；复核台仅使用只读 URI 连接；
- 复核台只注册 GET 路由；POST/PUT/PATCH/DELETE 返回 405；
- 不提供修改配方、删除运行、触发抓取、执行命令或读取任意文件的接口；
- 候选选择器仅作为报告线索，工具不会自动写回任何配方文件。

## 5. 输出使用限制

稳定性评分、候选建议和回归结论均为工程辅助信号，不等同于业务正确性证明。合并或发布配方前，仍需人工核验 DOM、字段语义与数据质量。报告中的“失败”用于提示契约风险，不构成对目标站点的评价或事实认定。

## 6. 不做的事

本项目明确不实现：真实抓取、代理池、Cookie 管理、验证码处理、反爬规避、浏览器渲染、截图、视觉回归、自动改写生产配方、自动提交选择器、分布式调度、任务队列、站点地图、WARC/HAR/RSS/OAI-PMH、内容变更监测、链接巡检、表单填报 RPA、机器学习、登录权限、多租户、外部数据库或远程 API。

如需接入真实采集链路，应在本项目之外独立评估授权、robots 约定、访问频率、个人信息保护与组织合规要求。
